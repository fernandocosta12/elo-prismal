# Valdora: Ecos do Véu

RPG de navegador (protótipo), visto de cima, com classes no estilo Ragnarok, missões, profissões, masmorra e modo online.

Jogar: https://fernandocosta12.github.io/elo-prismal/valdora/

- Funciona no PC e no celular (na horizontal). O progresso fica salvo no navegador de cada pessoa.
- **Online:** crie `online.json` nesta pasta com `{"url": "https://SEU-PROJETO.supabase.co", "key": "SUA-CHAVE-ANON"}` (Supabase, plano gratuito). Quem abrir o jogo já entra online e vê os outros jogadores no mesmo mapa.
